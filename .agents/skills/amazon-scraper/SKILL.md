# Amazon Scraper

## When to Apply
Use when extracting product information, tracking prices, analyzing reviews, or monitoring product availability on Amazon.

## Core Concepts
- **Product extraction**: Gather product details and specifications
- **Review analysis**: Collect and analyze customer reviews
- **Price tracking**: Monitor price changes over time
- **Availability monitoring**: Track stock status
- **Search optimization**: Efficient product discovery
- **Anti-bot handling**: Navigate anti-scraping measures

## Implementation
```
1. Define search criteria and target products
2. Navigate to Amazon search or product page
3. Handle any anti-bot verification
4. Extract product details, price, availability
5. Collect reviews if needed
6. Store data with timestamps
7. Set up monitoring for changes
```

## Best Practices
- Use appropriate request intervals
- Handle CAPTCHA and verification challenges
- Respect Amazon's terms of service
- Store data with timestamps for tracking
- Consider using Amazon Product Advertising API

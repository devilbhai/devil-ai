# Cloud Security

## When to Apply
Use this skill for cloud security assessments, misconfiguration detection, IAM auditing, and compliance scanning across AWS, Azure, and GCP.

## Core Concepts
- Cloud security posture management (CSPM)
- Identity and access management (IAM) auditing
- Storage security (S3, Blob, GCS)
- Network security in cloud
- Logging and monitoring
- Compliance frameworks (CIS, SOC2, PCI-DSS)

## Common Misconfigurations
- Public S3/Blob/GCS buckets
- Overly permissive IAM policies
- Unrestricted security groups
- Missing encryption
- Logging disabled

## Tools
- Prowler, ScoutSuite, Pacu, Checkov, Trivy

# Cryptography

## When to Use
Use this skill for cryptographic implementation reviews, protocol analysis, and key management audits.

## Core Concepts
- Symmetric encryption (AES, ChaCha20)
- Asymmetric encryption (RSA, ECC)
- Hash functions (SHA-256, bcrypt)
- TLS/SSL protocol analysis
- Side-channel attacks

## Tools
- OpenSSL, Hashcat, John the Ripper, SSLyze, testssl.sh

# Deep Thinking

## When to Apply
Use when facing complex problems that require multi-step reasoning, logical deduction, or abstract analysis. Apply for architectural decisions, algorithm design, debugging complex issues, or when the solution isn't immediately obvious.

## Core Concepts
- **Chain-of-thought reasoning**: Break complex problems into sequential reasoning steps
- **Decomposition**: Split large problems into manageable sub-problems
- **Abstraction layers**: Move between concrete and abstract representations
- **Logical deduction**: Apply formal logic to derive conclusions from premises
- **First-principles thinking**: Break down to fundamental truths before building up
- **Counterfactual reasoning**: Explore "what if" scenarios to test assumptions

## Implementation
```
Step 1: Identify the core problem and constraints
Step 2: Decompose into sub-problems
Step 3: Analyze each sub-problem independently
Step 4: Identify dependencies between sub-problems
Step 5: Synthesize solution from sub-solutions
Step 6: Validate against original constraints
```

## Best Practices
- Write out reasoning steps explicitly before jumping to solutions
- Challenge assumptions by asking "why?" at each level
- Consider edge cases and failure modes early
- Use diagrams or structured formats for complex relationships
- Verify conclusions by working backwards from the answer

# OKR Management

## When to Apply
Use this skill for setting goals, tracking progress, aligning teams, or conducting performance reviews.

## Core Concepts
- Objectives and Key Results
- Goal alignment
- Scoring and grading
- Regular check-ins
- OKR software tools

## Best Practices
- Set ambitious but achievable goals
- Limit to 3-5 objectives per quarter
- Include 3-5 key results per objective
- Make key results measurable
- Align team OKRs with company OKRs
- Review and score regularly
- Celebrate achievements

## OKR Structure
```markdown
## Objective: Improve Customer Satisfaction

### Key Results:
1. Increase NPS score from 40 to 60
2. Reduce support response time from 4 hours to 1 hour
3. Achieve 95% customer retention rate

### Initiatives:
- Implement live chat support
- Create customer success playbook
- Launch quarterly business reviews
```

## Scoring
- 0.0 - 0.3: Missed
- 0.4 - 0.6: Partial
- 0.7 - 1.0: Achieved

## Review Process
1. **Weekly**: Quick status updates
2. **Monthly**: Progress review, adjustments
3. **Quarterly**: Full review, scoring, planning
4. **Annual**: Strategic planning

## Communication
- Make OKRs visible to everyone
- Share progress regularly
- Celebrate wins
- Learn from misses
- Adjust as needed

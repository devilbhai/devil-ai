# OSINT (Open Source Intelligence)

## When to Apply
Use this skill for open source intelligence gathering, digital investigation, social media analysis, and public data research.

## Core Concepts
- Passive information gathering
- Social media intelligence (SOCMINT)
- Domain and IP investigation
- People search
- Data correlation
- Digital footprint analysis

## OSINT Categories
- **People** - Name, email, phone, username
- **Domain** - DNS, WHOIS, subdomains
- **IP** - Geolocation, services, reputation
- **Organization** - Company info, employees
- **Social Media** - Profiles, posts, connections
- **Images** - EXIF data, reverse search
- **Documents** - Metadata, leaked data

## People Investigation
- Username search (Sherlock)
- Email lookup
- Phone number lookup
- Social media profiles
- Professional networks
- Public records

## Domain Investigation
- DNS enumeration
- WHOIS lookup
- Subdomain discovery
- Certificate transparency
- Web archiving
- Technology fingerprinting

## IP Investigation
- Geolocation
- Reverse DNS
- Port scanning
- Service identification
- Reputation checking
- ASN information

## Tools
- **Sherlock** - Username OSINT
- **theHarvester** - Email/domain harvesting
- **Recon-ng** - OSINT framework
- **Maltego** - Visual OSINT
- **SpiderFoot** - Automated OSINT
- **OSINT Framework** - Tool collection
- **Shodan** - IoT search engine
- **Censys** - Internet search

## Social Media OSINT
- Profile analysis
- Post history
- Connection mapping
- Location tracking
- Sentiment analysis
- Temporal analysis

## Legal Considerations
- Only use publicly available information
- Respect privacy laws
- No unauthorized access
- Document sources
- Verify information
- Cross-reference findings

## Methodology
1. Define objectives
2. Collect data
3. Analyze data
4. Correlate findings
5. Verify information
6. Report results

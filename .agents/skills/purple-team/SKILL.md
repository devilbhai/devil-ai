# Purple Team Operations

## When to Apply
Use this skill for collaborative security testing where offensive and defensive teams work together to improve detection capabilities.

## Core Concepts
- Collaborative attack and defense testing
- Detection rule validation and gap analysis
- MITRE ATT&CK coverage mapping
- Continuous security improvement cycles

## Methodology
1. Plan - Define scope and objectives
2. Execute - Run attack techniques while defenders monitor
3. Detect - Validate if defenses detected the activity
4. Analyze - Review gaps and false negatives
5. Improve - Update rules and configurations
6. Repeat - Continuous validation cycle

## Tools
- Atomic Red Team, MITRE Caldera, Elastic SIEM

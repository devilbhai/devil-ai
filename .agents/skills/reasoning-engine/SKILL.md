# Reasoning Engine

## When to Apply
Use for systematic analysis requiring step-by-step reasoning, causal chain analysis, or when drawing parallels from known patterns to new situations. Apply for bug diagnosis, system design, and feature planning.

## Core Concepts
- **Causal reasoning**: Trace cause-effect chains through systems
- **Analogical reasoning**: Map known solutions to new problem domains
- **Inductive reasoning**: Generalize from specific observations
- **Deductive reasoning**: Apply general rules to specific cases
- **Abductive reasoning**: Infer the most likely explanation from incomplete data
- **Constraint satisfaction**: Find solutions that satisfy all requirements

## Implementation
```
1. Define the problem space and boundaries
2. Identify key variables and their relationships
3. Trace causal chains (A causes B, which causes C)
4. Search for analogous patterns in known solutions
5. Apply reasoning mode appropriate to available data
6. Test conclusion against edge cases
```

## Best Practices
- Explicitly state assumptions before reasoning from them
- Distinguish correlation from causation
- Use structured formats (tables, graphs) to visualize relationships
- When stuck, try a different reasoning mode (switch from inductive to deductive)
- Document reasoning chain for future reference and review

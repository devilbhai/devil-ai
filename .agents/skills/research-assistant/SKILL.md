# Research Assistant

## When to Apply
Use when gathering information, analyzing existing solutions, evaluating libraries/frameworks, or synthesizing findings from multiple sources. Apply before making technology choices or when exploring unfamiliar domains.

## Core Concepts
- **Systematic search**: Structured approach to finding relevant information
- **Source evaluation**: Assessing credibility and relevance of sources
- **Synthesis**: Combining multiple sources into coherent understanding
- **Citation tracking**: Managing references and maintaining attribution
- **Gap analysis**: Identifying missing information or unexplored areas
- **Framework application**: Using established analysis structures

## Implementation
```
1. Define research questions and scope
2. Identify key search terms and sources
3. Gather information systematically
4. Evaluate source quality and relevance
5. Synthesize findings into structured output
6. Document sources and reasoning chains
```

## Best Practices
- Start with authoritative sources (official docs, peer-reviewed)
- Cross-reference claims across multiple independent sources
- Note the date of information (technology changes rapidly)
- Distinguish between facts, opinions, and speculation
- Maintain a research log for complex investigations

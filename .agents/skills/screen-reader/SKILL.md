# Screen Reader

## When to Apply
Use when analyzing screen content, detecting UI elements, extracting text from displays, or testing application accessibility.

## Core Concepts
- **UI element detection**: Identify buttons, inputs, menus
- **Text extraction**: Read text from screen regions
- **Accessibility testing**: Verify ARIA compliance
- **OCR integration**: Extract text from images
- **Layout analysis**: Understand visual hierarchy
- **Element tree traversal**: Navigate UI structure

## Implementation
```
1. Capture screen or application state
2. Analyze UI element tree
3. Extract text and element properties
4. Identify interactive elements
5. Map visual to logical structure
6. Generate accessibility report
7. Suggest improvements if needed
```

## Best Practices
- Support multiple input formats (screenshots, DOM, accessibility trees)
- Handle dynamic content updates
- Respect user privacy when capturing screen content
- Provide actionable accessibility recommendations
- Test across different applications and platforms

# Stakeholder Communication

## When to Apply
Use this skill for communicating with stakeholders, writing executive summaries, or translating technical concepts.

## Core Concepts
- Audience analysis
- Message framing
- Visual communication
- Status reporting
- Risk communication
- Executive summaries

## Best Practices
- Know your audience
- Use plain language
- Focus on business impact
- Use visuals when possible
- Be concise and clear
- Highlight risks early
- Provide actionable insights

## Executive Summary Template
```markdown
## Executive Summary - Q4 2024

### Key Achievements
- Launched new payment system (on time, under budget)
- Reduced page load time by 40%
- Improved customer satisfaction by 15%

### Business Impact
- Revenue increase: $500K
- Cost savings: $200K
- Customer retention: +10%

### Risks
- Legacy system migration delayed 2 weeks
- New regulation requires compliance by Q1

### Next Quarter
- Complete mobile app redesign
- Implement AI features
- Hire 3 senior engineers
```

## Technical to Non-Technical
```markdown
### Before (Technical)
"Implemented Redis caching layer with 95% hit rate, reducing DB queries by 60% and improving p95 latency from 200ms to 50ms."

### After (Business)
"Made the website 4x faster by optimizing how we store data. Pages that took 2 seconds now load in half a second. This improves customer experience and reduces server costs."
```

## Status Report Format
```markdown
## Weekly Status Report

### Completed
- [x] Feature A - deployed to production
- [x] Bug fix B - resolved customer issue

### In Progress
- [ ] Feature C - 70% complete, on track
- [ ] Feature D - 50% complete, needs review

### Blocked
- [ ] Feature E - waiting for API access

### Metrics
- Deployment frequency: 5/week
- Bug resolution time: 2 hours avg
- Customer satisfaction: 4.5/5
```

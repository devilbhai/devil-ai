# Tab Manager

## When to Apply
Use when managing multiple browser tabs, coordinating actions across tabs, organizing tab groups, or optimizing browser memory usage.

## Core Concepts
- **Multi-tab coordination**: Actions across multiple tabs
- **Tab grouping**: Organize tabs by purpose or project
- **Memory optimization**: Reduce browser memory footprint
- **Tab lifecycle**: Create, focus, close tabs as needed
- **Cross-tab communication**: Share data between tabs
- **Session persistence**: Save and restore tab state

## Implementation
```
1. Identify tabs needed for task
2. Create or find existing tabs
3. Group related tabs logically
4. Coordinate actions across tabs
5. Monitor memory usage
6. Close unnecessary tabs
7. Save session state if needed
```

## Best Practices
- Limit concurrent tabs to prevent memory issues
- Use tab groups for related work
- Close tabs when no longer needed
- Save session state before closing
- Monitor for tab crashes or unresponsiveness

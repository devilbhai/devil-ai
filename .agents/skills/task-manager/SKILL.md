# Task Manager

## When to Apply
Use for organizing ongoing work, tracking multiple parallel tasks, managing priorities, or when coordinating work across sessions. Apply when context switching frequently or when tasks have varying urgency.

## Core Concepts
- **Priority queuing**: Rank tasks by urgency and importance
- **Deadline tracking**: Monitor time-sensitive commitments
- **Progress monitoring**: Track completion status across tasks
- **Context preservation**: Maintain state between sessions
- **Batch processing**: Group similar tasks for efficiency
- **Delegation patterns**: Know when to break work into sub-tasks

## Implementation
```
1. Capture all tasks in a structured format
2. Classify by priority (P0-P3) and type
3. Estimate effort and identify dependencies
4. Schedule execution based on constraints
5. Update status as work progresses
6. Review and re-prioritize regularly
```

## Best Practices
- Process task inbox at start of each session
- Use consistent priority levels across all tasks
- Break large tasks into smaller actionable items
- Track blockers explicitly, not just in-progress items
- Celebrate completed milestones to maintain momentum

## 🌟 Overview

**Devil AI** is a state-of-the-art, AI-powered autonomous coding assistant and standalone IDE built for senior software engineers, system architects, and high-velocity engineering teams. Powered by native OpenCode integration, Swarm multi-agent orchestration, Git Worktree isolation, and local RAG search, Devil AI transforms how software is researched, architected, refactored, and deployed.

---

## ⚡ Core Functions & Capabilities (61+ Features)

### 🤖 1. Swarm Multi-Agent Engine & Orchestration
- **Parallel Sub-Agents:** Spawns specialized agents (Researcher, Architect, Code Generator, Test Engineer, Refactorer) to execute complex multi-file changes simultaneously.
- **Autonomous Task Planning:** Breaks down high-level user prompts into structured execution steps with real-time progress indicators.
- **Pre-Cognitive Debugging:** Continuously analyzes code tracebacks and automatically applies self-healing bug fixes before errors hit production.

### 🌿 2. Git Worktree Isolation
- **Non-Destructive Experimentation:** Sub-agents run and test modifications in isolated Git worktree branches without touching or corrupting your primary working directory.
- **Instant Branch Merging:** Seamlessly merge or discard AI worktree branches with a single click or command.

### 🔍 3. Local RAG & CodeGraph Navigation
- **Local TF-IDF RAG:** Purely local semantic indexing — queries your entire codebase in milliseconds without uploading code to any third-party cloud.
- **Fuzzy File Search (fzf):** Instant file, symbol, and line search integrated directly into the chat prompt.
- **Visual CodeGraph:** Visualizes file dependencies, module imports, and architecture maps in real-time.

### 🎨 4. Liquid Glass UI & UX Excellence
- **macOS Dynamic Glassmorphism:** Translucent visual theme with dark mode, glowing accents, and smooth fluid animations.
- **Command Palette (`Cmd + K`):** Quick-action search menu to trigger 50+ workflows without leaving the keyboard.
- **Time-Travel History (`Cmd + Z`):** Undo and revert AI code modifications across multiple steps cleanly.
- **Voice Pair Programming:** Talk to Devil AI using Web Speech API voice input for hands-free pair programming.

### 📱 5. Telegram Remote Control & Tunneling
- **Mobile Remote Coding:** Connect Devil AI to your Telegram Bot and control your local agent remotely from your mobile device.
- **Secure Cloudflare Tunnels:** OTP-authenticated tunnels ensure zero unauthorized access during remote sessions.
- **Diff Approvals on Mobile:** Review code diffs and approve terminal command executions right from Telegram.

## 📥 Downloads & Installation

### Desktop App (macOS, Windows, Linux)
Download pre-built binary installers directly from [GitHub Releases](https://github.com/devilbhai/devil-ai/releases):

- **macOS Apple Silicon (M1/M2/M3):** `Devil-ai-1.14.0-mac-arm64.dmg`
- **macOS Intel:** `Devil-ai-1.14.0-mac-x64.dmg`
- **Windows:** `Devil-ai-1.14.0-win-x64.exe`

### CLI Quickstart

Install the zero-dependency CLI executable:

```bash
curl -fsSL https://raw.githubusercontent.com/devilbhai/devil-ai/main/packages/devil-ai-cli/install.sh | bash
```

Configure your Telegram Bot token:

```bash
devil-ai config --token YOUR_TELEGRAM_BOT_TOKEN
devil-ai start
```

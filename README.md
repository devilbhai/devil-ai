## 🌟 Overview

**Devil AI** is a state-of-the-art, AI-powered coding assistant and standalone IDE environment built for power-users, lead architects, and modern engineering teams. It integrates **61+ distinct capabilities**, ranging from low-latency native OpenCode CLI integration to Git Worktree branch isolation, multi-agent Swarm refactoring, local TF-IDF RAG indexing, and remote control via secure Telegram tunnels.

## 🚀 Download & Installation

### Desktop App (macOS & Windows)
Download pre-built binary installers directly from [GitHub Releases](https://github.com/devilbhai/devil-ai/releases).

- **macOS Apple Silicon (M1/M2/M3):** `Devil-ai-1.14.0-mac-arm64.dmg`
- **macOS Intel:** `Devil-ai-1.14.0-mac-x64.dmg`
- **Windows:** `Devil-ai-1.14.0-win-x64.exe`

### CLI Quickstart
Run our zero-dependency installer script to set up the CLI:

```bash
curl -fsSL https://raw.githubusercontent.com/devilbhai/devil-ai/main/packages/devil-ai-cli/install.sh | bash
```

## ✨ Core Highlights

- **🌿 Git Worktree Branch Isolation:** Agents test code modifications in temporary Git worktree branches without affecting your working directory.
- **🤖 Swarm Multi-Agent Engine:** Orchestrates specialized sub-agents (Researcher, Architect, Tester, Refactorer) in parallel trajectories.
- **🔍 Local RAG (TF-IDF Indexing):** Purely local semantic code search — zero network leakage or remote code indexing.
- **📱 Telegram Remote Pair Programming:** Interactively prompt, review diffs, and approve command executions from Telegram.
- **🎨 Liquid Glass Aesthetics:** macOS-native translucent glassmorphism UI with keyboard-first navigation (`Cmd+K`).
